Software y datos: casos de uso de agentes de IA

Agentes de IA para programar, analizar datos y automatizar planillas, incluso si no eres desarrollador. 13 casos, cada uno con el prompt listo para copiar.

  1. Asignarle una tarea pendiente de GitHub al agente de Copilot

    Asignas un issue a Copilot y él crea la rama, abre el pull request, trabaja la tarea, corre las pruebas y sube los cambios. Tú revisas, comentas y decides qué se publica.

    GitHub Copilot27 de octubre de 2026

  2. Convertir tu página web en una app para el celular

    Le das la dirección de tu sitio a Replit Agent y te arma una app con tu misma marca. Pides los cambios en palabras simples y te deja lista la lista de lo que necesitas para publicarla en las tiendas.

    Replit Agent27 de octubre de 2026

  3. Tener un "practicante de pruebas" que revise tu app todos los días

    El agente usa tu aplicación o tienda en línea como un cliente nuevo varias veces al día, anota lo que se rompe o confunde, con pasos y capturas, y te deja propuesto el arreglo.

    Grok Bot19 de octubre de 2026

  4. Crear tu propia herramienta para analizar bases de licitación

    Sin programar, le pides a Replit Agent una pequeña aplicación web: subes las bases de una licitación en PDF y te devuelve requisitos, plazos, criterios de evaluación y riesgos.

    Replit Agent18 de octubre de 2026

  5. Empezar una tarea de código en tu computador y que el agente la termine en la nube

    Devin explora tu proyecto en tu computador para entender su estructura y, cuando ya tiene el contexto, pasas la sesión a la nube para que siga solo hasta proponerte los cambios.

    Devin18 de octubre de 2026

  6. Que ChatGPT planifique y Codex programe

    Repartes el trabajo: ChatGPT diseña el plan y revisa el resultado, y Codex ejecuta cada paso en tu computador, corre las pruebas y te devuelve un resumen.

    OpenAI Codex16 de octubre de 2026

  7. Agregar una funcionalidad a un proyecto que ya existe

    El agente entiende la estructura de tu código, propone un plan, implementa el cambio en varios archivos y corre las pruebas antes de entregártelo.

    Cursor14 de octubre de 2026

  8. Documentar y agregar pruebas a código heredado

    El agente explica qué hace un módulo antiguo sin documentación, escribe comentarios útiles y crea pruebas que protegen su comportamiento actual.

    GitHub Copilot14 de octubre de 2026

  9. Resolver varios bugs pequeños en paralelo

    Le asignas una lista de errores reportados y el agente trabaja cada uno por separado, dejando un cambio revisable con su explicación para cada bug.

    OpenAI Codex14 de octubre de 2026

  10. Limpiar un Excel desordenado para un dashboard

    Claude Code escribe un script que normaliza columnas, fechas y nombres de clientes, y deja una tabla lista para conectar a Power BI.

    Claude Code9 de octubre de 2026

  11. Migrar macros de Excel a Python

    El agente lee el código VBA, explica qué hace cada macro y la reescribe en Python con pruebas para comprobar que da el mismo resultado.

    Claude Code8 de octubre de 2026

  12. Crear una landing page para validar un producto

    El agente construye una página simple con propuesta de valor, beneficios y formulario, lista para publicar y medir interés.

    Claude Code3 de octubre de 2026

  13. Probar tu aplicación web con un agente

    El agente recorre los flujos principales de tu app, anota errores con pasos para reproducirlos y propone correcciones en el código.

    Claude Code30 de septiembre de 2026
