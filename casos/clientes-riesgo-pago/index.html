Detectar clientes con riesgo de no pago

A partir del historial de pagos, el agente construye un scoring simple, explica qué variables pesan más y prioriza a quién contactar primero.

Agente: Claude CodeVentas y cobranzaPublicado el 7 de octubre de 2026

El prompt

Cópialo en Claude Code y reemplaza lo que está entre [corchetes] con tus datos.

Con el archivo historial_pagos.csv (cliente, fecha de vencimiento, fecha de pago, monto), construye un modelo simple que estime la probabilidad de atraso del próximo pago. Explica qué variables influyen más, valida el modelo con una parte de los datos y entrégame una lista priorizada de clientes a contactar esta semana.
