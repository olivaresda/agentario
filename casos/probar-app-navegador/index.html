Probar tu aplicación web con un agente

El agente recorre los flujos principales de tu app, anota errores con pasos para reproducirlos y propone correcciones en el código.

Agente: Claude CodeSoftware y datosPublicado el 30 de septiembre de 2026

El prompt

Cópialo en Claude Code y reemplaza lo que está entre [corchetes] con tus datos.

Levanta la app en local y recorre estos flujos: registro, inicio de sesión, [flujo principal] y cierre de sesión. Anota cada error con pasos para reproducirlo, lo esperado y lo obtenido. Luego propone una corrección para cada uno, pero no hagas cambios sin mostrármelos primero.

Tu experiencia vale más que el código

Este caso es parte de La experiencia es el código, un libro para profesionales que quieren crear sus propios agentes de IA sin programar.
