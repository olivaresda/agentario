Limpiar un Excel desordenado para un dashboard

Claude Code escribe un script que normaliza columnas, fechas y nombres de clientes, y deja una tabla lista para conectar a Power BI.

Agente: Claude CodeSoftware y datosPublicado el 9 de octubre de 2026

El prompt

Cópialo o ábrelo directo en Claude, y reemplaza lo que está entre [corchetes] con tus datos.

Abrir en Claude 
En esta carpeta hay un Excel de ventas con columnas inconsistentes, fechas en distintos formatos y clientes escritos de varias maneras. Escribe un script en Python que limpie y unifique los datos y genere ventas_limpias.csv. Explícame cada transformación y guarda un reporte de las filas que no pudiste corregir.
