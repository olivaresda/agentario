Documentar y agregar pruebas a código heredado

El agente explica qué hace un módulo antiguo sin documentación, escribe comentarios útiles y crea pruebas que protegen su comportamiento actual.

Agente: GitHub CopilotSoftware y datosPublicado el 14 de octubre de 2026

El prompt

Cópialo en GitHub Copilot y reemplaza lo que está entre [corchetes] con tus datos.

Este módulo no tiene documentación ni pruebas. Explícame qué hace cada función en lenguaje simple. Luego agrega documentación a las funciones públicas y escribe pruebas que capturen el comportamiento actual, incluidos los casos borde que encuentres. No cambies la lógica, aunque veas algo que parezca un error: anótalo aparte.
