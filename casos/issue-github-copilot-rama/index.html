Asignarle una tarea pendiente de GitHub al agente de Copilot

Asignas un issue a Copilot y él crea la rama, abre el pull request, trabaja la tarea, corre las pruebas y sube los cambios. Tú revisas, comentas y decides qué se publica.

Agente: GitHub CopilotSoftware y datosPublicado el 27 de octubre de 2026

Resultado real: Tras algunos intentos, resolvió una tarea real del backlog. Solo funcionó bien cuando el issue tenía instrucciones muy detalladas, y siempre partió desde la rama principal aunque le pidieran otra.

El prompt

Cópialo en GitHub Copilot o ábrelo directo en Claude, y reemplaza lo que está entre [corchetes] con tus datos.

Abrir en Claude 
Asígnale este issue de GitHub al agente de Copilot: [enlace al issue]. Antes de empezar, asegúrate de que trabaje desde la rama [nombre de la rama] y no desde la principal, y déjalo escrito en las instrucciones de la tarea. Al terminar, abre un pull request hacia [nombre de la rama] con un resumen breve de los cambios y no hagas merge hasta que yo lo revise.
